# --tmux mode (detached overnight runs)

Used when the user says `--tmux` (or "overnight"/"walk away"). The launcher
is GENERATED per job at init and DELETED at closeout. It is the only
supervisor — do not also wire Stop hooks (two supervisors compete).

## Launch procedure (skill side)

1. Run Flow steps 1-2 as usual (gate, init job file; `mode: tmux`).
2. Confirm permission mode with the user ONCE — default
   `--permission-mode acceptEdits`. Never silently widen permissions.
3. Write `.claude/jobs/<slug>/run-job.sh` from the template below with
   `<ABS_JOB_PATH>` replaced by the absolute job-file path.
4. Start detached (guard against a stale session first):
   `tmux has-session -t <slug> 2>/dev/null && { echo "session exists — attach or kill it first"; exit 1; }`
   `tmux new-session -d -s <slug> 'bash .claude/jobs/<slug>/run-job.sh 2>&1 | tee -a .claude/jobs/<slug>/run.log'`
5. Tell the user: `tmux attach -t <slug>` to watch; the job file is the live
   status board; resume-after-crash is the normal `resume <slug>` path.

## Launcher template

    #!/usr/bin/env bash
    # Generated by /my-utils:long-running-job --tmux. Deleted at closeout.
    set -u
    LRJ_QUOTA_SLEEP="${LRJ_QUOTA_SLEEP:-1800}"
    JOB="<ABS_JOB_PATH>"
    STALLS=0
    [ -f "$JOB" ] || { echo "[job] ERROR — job file missing at $JOB"; exit 1; }
    pending() { grep -cE '^\|[[:space:]]*[0-9]+[[:space:]]*\|.*\|[[:space:]]*(next|pending)[[:space:]]*\|' "$JOB"; }
    while [ "$(pending)" -gt 0 ]; do
      grep -q '^status: paused-failed' "$JOB" && { echo "[job] paused-failed — stopping"; break; }
      BEFORE=$(shasum -a 256 "$JOB" | awk '{print $1}')
      claude -p "Long-running job unit. Read the job file at $JOB and the plan it points to. First reconcile the Units table against git log (reality wins). Then execute the unit marked 'next' via superpowers:executing-plans + TDD — ONE atomic commit. Run gates (typecheck + lint + the unit's tests). Gates green: mark the unit 'done' with its commit hash, set the next unit 'next', rewrite Handoff, append one Log line. Gates red after two fix attempts: set frontmatter 'status: paused-failed' and stop." --permission-mode acceptEdits
      AFTER=$(shasum -a 256 "$JOB" | awk '{print $1}')
      if grep -q '^status: paused-quota' "$JOB"; then
        echo "[job] quota pause — sleeping ${LRJ_QUOTA_SLEEP}s"; sleep "$LRJ_QUOTA_SLEEP"; STALLS=0; continue
      fi
      if [ "$BEFORE" = "$AFTER" ]; then
        STALLS=$((STALLS+1)); echo "[job] stall $STALLS (claude ran, job file unchanged)"
        [ "$STALLS" -ge 2 ] && { echo "[job] two stalls — stopping for human review"; break; }
      else
        STALLS=0
      fi
    done
    echo "[job] loop exit: $(grep '^status:' "$JOB" | head -1)"

Notes: `LRJ_QUOTA_SLEEP` overridable for testing. Stall guard breaks after
two consecutive no-change runs so a wedged worker cannot spin forever.
